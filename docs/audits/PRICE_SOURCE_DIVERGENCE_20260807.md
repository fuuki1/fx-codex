# 価格ソース乖離の実態調査（Data Truth Plane）

**作成日:** 2026-08-07
**対象:** 方向性 decision 全 5,385 件（15m / 1h / 4h / 1d / fusion, 全通貨）
**コード:** `[DEV]` HEAD `98ff701`
**⚠️ PRODは未変更。** 実機DBと tick tape を読み取り専用で参照しただけである。

---

## 結論

**1. 乖離そのものは小さく、偏りもない。**
decision の close と同時刻 tick mid の差は中央値 **1.6 pips**、
符号は **49.6% が正**（= 系統的なズレではなくノイズ）。

**2. しかし 15m / 1h では stop 距離が 4 pips しかないため、乖離が支配的になる。**

| timeframe | stop距離(中央値) | 乖離(中央値) | **乖離/stop** | t0で既にstop/target超過 |
|---|---:|---:|---:|---:|
| **15m** | **4.03 pips** | 1.65 pips | **0.410** | **10.9%** |
| **1h** | **4.15 pips** | 1.60 pips | **0.385** | **10.6%** |
| 4h | 70.32 pips | 1.60 pips | 0.023 | **0.0%** |
| 1d | 153.96 pips | 1.55 pips | 0.010 | **0.0%** |
| fusion | 41.35 pips | 1.25 pips | 0.030 | 0.0% |

**3. 真因は乖離ではなく、15m/1h の ATR 倍率が 0.25〜0.5 と極端に小さいことである。**

| timeframe | ATR倍率(実測中央値) |
|---|---:|
| **15m** | **0.500** |
| **1h** | **0.250** |
| 4h | 2.500 |
| 1d | 2.500 |
| fusion | 2.500 |

4h/1d は 2.5 ATR で乖離の影響が 2〜3% に収まる。
**15m/1h だけが 1/5〜1/10 の倍率であり、そこだけ乖離が意味を持つ。**

## 2. 乖離の分布

**評価成功 5,266 / 5,385（97.8%）**。失敗119件はすべて「2分以内に tick 無し」。

decision timestamp から最も近い tick（±2分以内）の mid との差:

| 統計 | \|乖離\| (pips) |
|---|---:|
| p10 | 0.250 |
| p25 | 0.700 |
| **p50** | **1.600** |
| p75 | 3.600 |
| p90 | 6.800 |
| p99 | 33.400 |
| max | 138.200 |

**符号付き乖離:** 平均 −0.0234 pips、中央値 **0.0000**、正の割合 **49.6%**。

→ **系統的バイアスは無い。** OANDA が常に高い/低いという関係ではなく、
両ソースの観測タイミングと気配の揺らぎによるノイズである。

**時刻ずれは原因ではない:** decision と最近傍 tick の時間差は
中央値 **0.7秒**、p90 4.5秒、最大 72.6秒。

### 通貨別

| symbol | n | 中央値 | p90 |
|---|---:|---:|---:|
| EURUSD | 2,607 | 1.05 pips | 3.30 pips |
| GBPUSD | 54 | 1.08 pips | 3.00 pips |
| **USDJPY** | 2,605 | **2.80 pips** | **10.50 pips** |

USDJPY の乖離が EURUSD の約2.7倍。

## 3. 相対的な深刻さ

**絶対値ではなく「stop 距離に対する比」で見ると問題が見える。**

| 統計 | 乖離 / stop距離 |
|---|---:|
| p25 | 0.010 |
| p50 | 0.034 |
| p75 | **0.296** |
| p90 | **0.743** |
| p99 | **2.105** |
| max | 8.412 |

| 閾値 | 該当件数 |
|---|---:|
| 乖離 ≥ stop の 25% | **1,462 / 5,266（27.8%）** |
| 乖離 ≥ stop の 50% | 857 / 5,266（16.3%） |
| **乖離 ≥ stop の 100%** | **300 / 5,266（5.7%）** |

**5.7% の decision は、乖離だけで stop 距離を丸ごと超えている。**

### t0 時点で既に stop/target を割っている decision

| 種別 | 件数 |
|---|---:|
| stop 超過 | 133（2.5%） |
| target 超過 | 124（2.4%） |
| **いずれか** | **257（4.9%）** |

これらは**建玉した瞬間に決済条件を満たしている**ため、
R の分母が潰れるか、即時決済になる。

`PATH_DEPENDENT_SIGNAL_AUDIT_20260807.md` で棄却率17%となった直接の原因である。

## 4. 真因: 15m/1h の ATR 倍率

timeframe 別に分解すると、**乖離の絶対値はほぼ一定（1.25〜1.65 pips）**である一方、
**stop 距離が 4 pips と 154 pips で 38倍違う**。

| timeframe | stop | 乖離 | 比 | 乖離>stop の割合 |
|---|---:|---:|---:|---:|
| **15m** | 4.03p | 1.65p | **0.410** | **14.6%** |
| **1h** | 4.15p | 1.60p | **0.385** | **10.7%** |
| 4h | 70.32p | 1.60p | 0.023 | **0.0%** |
| 1d | 153.96p | 1.55p | 0.010 | **0.0%** |

ATR 倍率の実測:

| timeframe | ATR倍率 | 生ATR中央値 |
|---|---:|---:|
| 15m | **0.500** | 0.001077 |
| 1h | **0.250** | 0.001752 |
| 4h | 2.500 | 0.250509 |
| 1d | 2.500 | 0.617322 |

**これは意図された設計変更である。**
memory `atr_multiple_per_timeframe_implemented_20260730`
（「A案: 15m/1hのSL距離0.25ATR化」）に記録があり、
ラベル生成率を 0% → 66.9% へ上げる目的だった。

**その副作用がここで観測されている。**
memory `tight_stop_price_source_mismatch_20260730`
（「SL短縮の副作用: 判断closeと実tickが10-14pips乖離」）は
この現象を既に指摘していたが、**規模は定量化されていなかった。**

### 参考: 2.5 ATR だった場合

| timeframe | 現在の乖離/stop | 2.5ATR相当 |
|---|---:|---:|
| 15m | 0.369 | 約 0.037 |
| 1h | 0.317 | 約 0.032 |

※ 単純な10倍換算による概算であり、実測ではない（**推論**）。

## 5. これが下流に与える影響

| 影響先 | 内容 |
|---|---|
| ラベル品質 | 5.7% は stop 距離を超える乖離を持ち、R が意味を失う |
| 経路監査 | `PATH_DEPENDENT_SIGNAL_AUDIT` で 17% が評価不能 |
| 建玉判定 | 4.9% は t0 で既に決済条件を満たす |
| net-R | 分母が意図と異なるため、R 正規化が壊れる |

**⚠️ 重要:** これは P0-C で修正した `+46.4R` の分母崩壊と**同じ機構**である。
P0-C は建玉時に quarantine するが、**decision 段階では何も検出していない。**

## 6. 言えないこと

1. **どちらのソースが「正しい」かは判定していない。**
   OANDA と Dukascopy は別の流動性プールであり、
   どちらも「その業者での実勢」として正しい可能性がある
2. **乖離を消せば黒字化するとは言えない。**
   `GROSS_EDGE_DECOMPOSITION` と `PATH_DEPENDENT_SIGNAL_AUDIT` は
   方向自体に情報が無いことを示している
3. **2.5 ATR に戻せば改善するとは言えない。**
   0.25 ATR 化はラベル生成率を上げるために行われた変更であり、
   戻せばラベルが再び出なくなる可能性がある。トレードオフの測定が必要
4. **因果関係ではない。** 乖離と成績の関係は測っていない

## 7. 次に測るべきこと

### 7.1 decision 段階の分母ガード（最優先・実装候補）

P0-C は**建玉時**に `rd >= 2 × spread` を課しているが、
decision 生成時には同等の検査が無い。

`stop` を決める時点で、
**同時刻の実 spread に対する最小距離**を要求すれば、
5.7% の「乖離が stop を超える」decision を発生源で防げる。

⚠️ ただし `FX_CODEX_TARGET_ARCHITECTURE_INTEGRATION_PLAN.md` §8 により
**TP/SL 距離は独立した設計承認なしに変更しない。**
本文書は測定であり、変更提案ではない。

### 7.2 ラベル生成率とのトレードオフ測定

0.25 ATR 化はラベル生成率 0%→66.9% を目的とした。
現在の生成率と、2.5 ATR に戻した場合の生成率を実測すれば、
**「ラベルが出ること」と「R が意味を持つこと」のどちらを取るか**を
数値で判断できる。

### 7.3 二重ソース構成そのものの評価

判断が OANDA、検証が Dukascopy という構成は
`GAP` 文書の Data Truth Plane（Consensus / Trust）に該当する。
同一ソースで判断・検証する選択肢の可否は未評価である。

## 付録: 手法

```
decision timestamp の ±2分以内で最も近い tick を選び、
その mid と decision の close を比較する。
pip = 0.01 (JPY quote) / 0.0001 (それ以外)
t0 breach 判定は executable 価格（long=ask, short=bid）で行う。
```

ローダは `fx_intel.virtual_portfolio_replay.load_quote_tape`。
